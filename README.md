## 📌 Introduction
**NUI Tool** helps developers quickly convert graphical assets into **C arrays** for embedded systems.

It is designed to work seamlessly with displays like:
- SSD1306 (OLED)
- ST7789 (TFT LCD)
- Other embedded displays

---

## ✨ Features
- Convert images to **1-bit monochrome bitmap**
- Convert fonts to embedded format
- Resize images (with aspect ratio lock)
- Export data as **C array**
- Simple and intuitive UI

---

## 🧰 Supported Formats

### Input
- PNG
- JPG / JPEG
- BMP

### Output
- 1-bit, RGB565, RGB888 image (C array)
- Font data (C format)

## 🚀 Installation

1. Download the latest release from GitHub.
 👉 https://github.com/your-repo/NUI-Tool/releases
2. Extract the ZIP archive.
3. Run `NUI_Tool.exe`.

## 🖼️ Usage
### Image Conversion
1. Open image
2. Resize if needed
3. Choose conversion format: RGB565, RGB888, Bitmap-1bit.
4. Generate Image
### Font Conversion
1. Select font
2. Choose size
3. Set name font
4. Generate Image
